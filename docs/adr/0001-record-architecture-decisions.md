# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** YYYY-MM-DD

## Context

Choices made while building this project (tools, data splits, models, hosting) need to be explainable later, in reviews and interviews.

## Decision

Every significant choice gets a short ADR in `docs/adr/`, numbered in order, using this format:
Context → Decision → Consequences. Copy this file to start a new one.

## Consequences

- Reviewers can see why, not just what.
- Superseded decisions stay in the folder, marked "Superseded by ADR 00XX".
